# BazaarPlusPlus Android Runtime

**Game Source APK**: An official The Bazaar APK selected by the user and read only locally.

**Game Version**: A verified local copy identified by its complete-file SHA-256.

**Runtime Instance**: A future executable projection of one Game Version. The first prototype only imports and verifies.

**Mod Profile**: A future selection of built-in BazaarPlusPlus and user-imported Mods associated with one Game Version.
